# Free-City-

Mini-démo web inspirée du film **Free Guy** : une ville stylisée, des PNJ avec lunettes de soleil
et des joueurs réels qui se déplacent dans la même scène. Attrapez les bonus sans vous faire
percuter par les voitures pour gagner.

## Lancer la démo

Ouvrez `index.html` dans un navigateur moderne. Utilisez les flèches ou WASD pour déplacer le
personnage principal et atteindre 10 bonus. Vous pouvez sprinter avec Shift, mettre en pause,
ou réinitialiser la partie depuis les boutons de la scène.

## Obtenir un lien partageable

Ce projet n’est pas hébergé automatiquement dans cet environnement. Pour obtenir un lien
partageable, vous pouvez par exemple :

1. Pousser le dossier sur GitHub.
2. Activer GitHub Pages sur la branche principale, dossier racine.
3. Utiliser l’URL fournie par GitHub Pages comme lien public.

## Publier sur GitHub

Vous devez créer un dépôt GitHub et avoir des identifiants (ou un token). Ensuite, exécutez :

```bash
git remote add origin https://github.com/<votre-compte>/free-city.git
git push -u origin work
```

Puis activez GitHub Pages (branche `work`, dossier racine) pour obtenir un lien public.
